# REQ-FR-NOTE-001: Create Note

**Type:** Functional Requirement  
**Status:** Draft  
**Domain:** Note Management

## Requirement

The system shall allow a user to create a note with a title and content.

## Acceptance Criteria

- AC-001: A user can create a note with a non-empty title.
- AC-002: A user can provide text content.
- AC-003: The system assigns a unique identifier to every newly created note.
- AC-004: A successfully created note can be retrieved by its identifier.
